       Simula carga realista de usuarios

    4️⃣ PRUEBA DE ESTRÉS
       Prueba límites del sistema

🔧 PARÁMETROS PRINCIPALES
═══════════════════════════════════════════════════════════════════════════════

    -f, --locustfile FILE       Archivo con definición de usuarios
    -u, --users NUM             Número total de usuarios virtuales
    -r, --spawn-rate NUM        Usuarios generados por segundo
    --run-time DURATION         Duración (60s, 5m, 1h, etc.)
    --host URL                  URL base de la API
    --headless                  Sin interfaz gráfica
    --csv FILE                  Exportar resultados en CSV
    --html FILE                 Generar reporte HTML
    --workers NUM               Modo distribuido (workers)
    --loglevel LEVEL            DEBUG, INFO, WARNING, ERROR

⚡ SOLUCIÓN RÁPIDA DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

    ❌ "Connection refused"
       ✅ Verifica: curl http://localhost:8000

    ❌ "Locust not found"
       ✅ Instala: pip install -r requirements.txt

    ❌ "Too many failures"
       ✅ Reduce usuarios: locust -u 10 (antes de 50)

    ❌ "Cannot import module"
       ✅ Actualiza dependencias: pip install --upgrade -r requirements.txt

    ❌ "Port already in use"
       ✅ Usa otro puerto: locust --web-port 9000
